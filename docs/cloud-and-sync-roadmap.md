# 云端与同步状态

Personal Academic Radar 支持可选的 Sites 部署与应用记录同步。本站按用户授权公开全部六页面和反馈操作，包括研究画像、偏好与检查信息；持有链接的人均可浏览和保存反馈，无须 ChatGPT 登录。来源编辑、画像确认及手动文献、摘要和 PDF 管理仍在本地执行。部署与配置以 [Sites 部署与数据同步](cloud-sync.md) 为准。

本地私有 SQLite 仍是采集、语义评分、来源配置、画像版本确认和 PDF 管理的主库。云端 D1 保存经完整性校验的应用记录快照，云端反馈先回传本地，再同步完整快照。每次切换只发生在全部记录验证通过后；失败时继续提供上一完整版本。电脑离线时可访问云端已有数据，后续采集和评分等待本地恢复。

每日默认只判断从未有过 Codex 判断的合格论文。120 篇是单批上限，不是每日配额；旧标准、画像调整、反馈或摘要变化都不会自动让已判断论文重评。用户明确要求时可运行手动重评，历史推荐快照始终保留。

GitHub 与 Sites 源仓库只同步代码、测试、schema 和通用示例。原 SQLite、WAL、PDF、配置、画像原文件、凭据、队列、结果、日志和备份保留在私有状态目录。数据同步与源代码发布使用各自明确的通道；论文数据更新不需要重新部署站点。

当前使用一套研究画像和共同反馈记录，没有按访问者隔离的个人账户或画像；云端独立采集与语义评分尚未提供。
