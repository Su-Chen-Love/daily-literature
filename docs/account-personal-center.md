# 账号资料与精简个人中心（候选）

此候选继续使用现有 Site、可信所有者身份和 D1，不修改 ChatGPT 账户资料，不新增外部存储或凭据。八张原创头像已通过同一仓库 main 素材提交合法交付并核验，运行时使用 384×384 WebP，每张约 9–16KB；原 bundle 已转为独立资源及 SHA-256 清单。

## 数据与并发

云端 `/api/account/settings` 按已配置所有者身份的 SHA-256 键，独立保存在原 D1 `pointers` 表中。记录包含单调版本、资料、显示偏好和更新时间；不会进入研究画像事件队列，不改变采集、评分、反馈审阅时间边界。GET 和 POST 均要求可信所有者；POST 要求同源 Origin、受限 JSON、长度与头像格式校验。头像使用固定预设标识或有大小上限的图像 data URI，均可跨设备读取，不使用临时 blob URL。

POST 提交稀疏字段及 `base_version`，SQL 原子比较版本。不同字段冲突可读取最新版本后合并；同一字段冲突保留输入、显示失败并等待明确重试。旧 localStorage 仅在云端对应资料或显示设置没有值时迁移，已有云端值优先；新设备默认值不覆盖已有账号设置。localStorage 是缓存，并保存未同步输入和原始基准，刷新后仍核验冲突，不盲目覆盖。

称呼、简介在停顿 650ms 或失焦后保存；中文 IME 合成期间不发送。头像选择后自动保存，无独立保存按钮。取消预设面板不更改资料；本地上传仍保留。失败提示和重试按钮保留；正常成功不显示常驻小字。关闭会刷新待保存编辑，导航使用受版本保护的 keepalive 与持久待同步输入。冲突期间禁止导航时自动重试覆盖。

## 显示与精简

保留系统无衬线和阅读衬线；旧 `humanist`、`mono` 持久化值分别映射自托管 Ma Shan Zheng 楷书及 ZCOOL KuaiLe 手写体。两款从 Google Fonts 官方仓库取得，OFL 1.1 许可随源码保存在 `static/fonts/`，转换 WOFF2，没有安装系统字体。跨平台加载同一字体文件，不依赖设备是否有仿宋或楷体。

官方来源：
- https://github.com/google/fonts/tree/main/ofl/mashanzheng
- https://github.com/google/fonts/tree/main/ofl/zcoolkuaile

主题展示名为鼠尾草绿、素净纸白、暖沙浅棕、晨雾淡蓝；配色值与 sage/paper/sand/mist 持久化键不变。

中心去掉重复研究兴趣跳转、恢复默认、成功存储小字以及下一步操作/更新数据库/需要处理模块和专用复制逻辑。同步中心只展示实际同步、检查、推荐更新时间及数据库状态。时间显式采用 Asia/Shanghai 并标注北京时间。去掉阅读状态全部 UI、筛选及判断置信度展示；旧数据库字段和旧 API 兼容保留，新的反馈提交不重置旧阅读状态。

## 本机证据

271 项 Python 测试通过；实际 Site Worker、MCP、账号接口/HTTP 身份与 CSRF、稀疏更新、CAS 并发、过期拒绝和非法头像测试通过。两套独立浏览器存储共享合成账号数据库，已验证资料和字体主题跨来源读取、不同字段合并、相同字段冲突、冲突输入刷新保留和明确重试。楷书与手写体实际渲染宽度不同，已截图核验。

八个头像均通过加载、自动保存及刷新恢复，独立浏览器存储也能读到所选头像；取消与 Escape 返回正确焦点。仍需独立生产账号跨会话 QA。本机上传的原生选择器验收被浏览器接管打断，未改变扩展权限，不记作通过。未向生产账号保存测试资料或研究画像。
