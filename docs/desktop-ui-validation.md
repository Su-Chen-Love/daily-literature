# 每日文献桌面界面

系统无衬线和浅鼠尾草为默认显示方案。显示设置提供真实字体和配色预览，自动保存在当前浏览器，并同步到同源标签页。存储不可用时明确提示未保存；关闭、重开、刷新和恢复默认均经过验收。

## 验收范围

在正式 Site v10 源码提交 `cc427819cadfad82b02231caf72a5188c5ff0d09` 上叠加共享 UI，使用合成数据运行实际 Worker；没有以仓库旧 Worker 替换线上 v10。桌面浏览器共通过 62 项检查，覆盖六页、1440/1280 宽度、设置保存与失败、跨标签页、重复点击、网络中断、旧版本冲突和输入保留。

真实浏览器发现并修复 v10 的原生兴趣表单失败：`no-referrer` 会让原生 POST 的 Origin 变成 null。改用 `same-origin`，保留服务器的精确来源与所有者校验，也继续阻止跨站引用信息。浏览器页面错误现有导航和恢复入口，API 仍返回 JSON。

实际 v10 Worker 与正式 Python 消费者完成同内容事件闭环：2 条事件消费并确认到游标 2，重复导入 0 条，待处理状态清零。原生表单仅规范换行；兴趣语义、阈值、偏好说明、已有评分和推荐历史不变。此为隔离合成验收，不等同于生产新事件已验收。

正式 Python 回归 265 项、共享 UI 一致性、两个 Worker 的构建和产物验证、v10 所有者访问/事件协议/MCP 回归均通过。
