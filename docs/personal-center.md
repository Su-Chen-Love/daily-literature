# 个人中心与单一研究画像

左下角个人中心收纳应用内资料、显示设置、同步与检查。称呼、简介和头像仅保存在当前浏览器，不修改 ChatGPT 账号，也不上传到同步数据库。字体提供系统无衬线、阅读衬线、人文无衬线和等宽；配色提供浅鼠尾草、纸白、暖沙、雾蓝。默认值保持系统无衬线和浅鼠尾草，兼容原来的浏览器偏好。

同步、实际本机检查和推荐导入各自显示时间。请求登记只意味着等待接收，不代表采集或评分完成。旧 `/status` 地址转到个人中心的同步与检查栏目。CLI `verify` 和本机中心检查完成后记录轻量时间戳，云端只展示已同步的实际本机记录；没有记录时显示尚无记录。

画像只保留一个正文编辑区。已有独立筛选说明会先合并显示在正文末尾，不截断、不丢弃；用户保存并确认后，说明成为正文的一部分。新版表单固定阈值 0.7，并清空已并入正文的旧说明字段。旧协议和已排队事件仍按原始值校验，未来筛选固定使用 0.7；已冻结旧队列仍按其阈值导入，已有判断和每日历史不重评。同内容事件只更新审计、偏好和游标，不刷新画像确认时间或重写画像文件，避免推进待审阅反馈的时间边界。

反馈理由可空，本地、同步消费者、云端 API 和 SQL 写入规则一致。阅读状态仍保存在详情和文献库筛选中，主要卡片仅保留收藏、反馈和详情。收藏、稍后阅读与已读视图包含所有已保存条目，即使原分数低于 0.7 或收录状态后来改变；默认推荐视图继续应用推荐条件。

## 源码与验收

正式站点继续基于官方 Site v12 源码 `3abb0c1b71dc8b2feeec3331750b448b8dbcfa81`。仓库 `sites/` 只用于共享 UI 与旧 Worker 兼容回归，不能部署覆盖正式站点。`sites/patches/personal-center-v12.patch` 保存针对该正式源码的最小服务端变更；共享模板和静态资源仍来自 `src/academic_radar`。没有合并全云端迁移分支，也没有切换 writer mode。

Python 回归与两个 Worker 的测试覆盖空理由、旧说明合并、固定阈值、事件基础版本、状态迁移，以及低分/排除后收藏和阅读记录可见性。云浏览器还需验收头像、四字体四配色、刷新与跨标签保存、关闭和键盘焦点、失败与重复操作。
